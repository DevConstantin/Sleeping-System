# Sleeping System
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.5.1.

# About
Sleeping system. This system:    
- Plays a sleeping animation when players sit in a seat instance that is designated as a bed (sample code included in seat instances within the rbxlx file)    
- Covers player characters in blankets (rendered locally on the client)  
- Players can set their desired sleeping position (character animation will be updated) and blanket color (stored in a DataStore value on the server) 

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "Sleeping System.rbxlx"
```

Next, open `Sleeping System.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
